# Contributing

All changes require review through a pull request into `main`.

1. Work on `develope-for-ai`.
2. Keep one bounded chapter in review at a time.
3. Follow `MASTER_PLAN.md`, `STYLE_GUIDE.md`, and `AGENTS.md`.
4. Run `python3 .ai/validate.py` and `git diff --check`.
5. Verify citations and artifacts manually before merging.

Never commit credentials or private customer information.
