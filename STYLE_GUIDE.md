# SaaS OS Style Guide

- Write primarily in clear, professional Vietnamese.
- Prefer operational language, concrete examples, and reusable artifacts.
- Separate verified fact, inference, and recommendation.
- Cite primary sources with direct URLs and the latest verification date.
- Define new terminology and cross-reference existing chapters instead of duplicating them.
- Follow the Standard Chapter Template and Quality Standard in `MASTER_PLAN.md`.
- Use sentence case for headings and concise tables for exact mappings.
- Do not use fabricated case studies, quotations, statistics, or benchmarks.
